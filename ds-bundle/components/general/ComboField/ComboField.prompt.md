ComboField from dwes. Use via `window.DWES.ComboField` (bundle loaded from the root `_ds_bundle.js`). Wrap the tree in `<ThemeProvider>` (full provider chain in README.md — components read theme/i18n from that context).

Editable combobox: text input + native <datalist> suggestions.
The user can pick a preset OR type a custom value (free text accepted).
